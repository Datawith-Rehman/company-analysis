📊 Data Analysis Portfolio: Profit Insights & Visualization
🚀 Project Overview

This project demonstrates a complete data analysis workflow — from raw data cleaning to insightful visualizations and interactive dashboards. The main focus is on analyzing profit trends and business performance.

🧹 Data Cleaning (Python - Pandas)
Handled missing and inconsistent data
Removed duplicates and corrected data types
Standardized columns for better analysis
Prepared dataset for SQL and visualization
🗄️ SQL Analysis
Performed SQL queries to extract insights
Used:
Aggregations (SUM, AVG, COUNT)
GROUP BY and filtering (WHERE, HAVING)
Identified key profit trends and performance metrics
📈 Data Visualization
Created visualizations to understand:
Profit distribution
Sales trends over time
Category-wise performance
Used charts and graphs for clear storytelling
